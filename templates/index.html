How these parameters are used

For each continuous variable: similarity = c / (c + |value − reference|). The coefficient c uses the same unit as the variable; a difference equal to c gives a similarity of 0.5. The final score is the weighted sum. These are research settings, not the variety's tolerance limits.

The supplied 40/35/25 category weights cannot be used directly here. Texture requires a categorical distance method and is excluded from this draft.
